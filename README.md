# Project001 — 物流机器人视觉模块

## 项目简介

本项目是面向工业创新竞赛的**物流机器人视觉导航与任务执行模块**，基于 Python + OpenCV 实现，运行于树莓派（Raspberry Pi）平台。模块负责颜色目标识别、AprilTag 站点定位、任务扫码读取、串口协议通信和任务状态机管理，与 STM32 F407 控制器协同工作，完成物料搬运全流程。

## 核心功能

### 视觉识别
- **多颜色目标追踪**：支持红、绿、蓝等多颜色目标的实时检测、轮廓过滤和目标关联
- **AprilTag 站点定位**：基于 36h11 字典的 AprilTag 检测，映射站点 ID
- **精定位**：抓取前进行坐标稳定采样，支持跳变拒绝和超时处理
- **相机标定**：支持标定参数加载和图像去畸变

### 任务管理
- **状态机驱动**：S0-S5 六状态工作流，覆盖待机、扫码、取料、放垫圈、装配全流程
- **超时恢复**：状态级超时自动触发 recover，支持最大恢复次数限制
- **安全门检查**：执行动作前检查限位、ToF 距离和抓取确认信号

### 通信协议
- **二进制协议**：树莓派与 F407 之间的帧式通信，包含心跳、ACK、DONE 三类应答
- **自动重连**：串口断线后按间隔重连，支持重连计数
- **协议仿真**：无需硬件即可测试通信重试和失败场景

### 运行观测
- **JSONL 日志**：每帧记录运行状态、动作日志和事件流
- **遥测采集**：树莓派 CPU 温度、电压告警等系统指标
- **错误帧归档**：按间隔保存无目标帧，供离线调参

## 快速开始

### 仿真模式（无需硬件）

```bash
python -m app.视觉应用 --mode simulation
```

仿真模式使用虚拟设备和固定事件驱动真实状态机，输出动作日志到 `logs/application_simulation.jsonl`。

### 实机模式

```bash
python -m app.视觉应用 \
    --mode live \
    --live-config config/实机配置.json \
    --max-runtime-s 300
```

实机模式需要连接相机、扫码器和 F407 控制器，按 `实机配置.json` 中的参数运行。

## 配置说明

实机模式依赖 `config/实机配置.json`，主要配置项：

| 配置段 | 说明 |
|--------|------|
| `camera` | 相机源、分辨率、帧率、重连间隔 |
| `scanner` | 扫码器模式（serial/camera_qr）、串口端口、波特率 |
| `controller` | F407 串口端口、波特率、写超时 |
| `protocol` | 心跳间隔、离线超时、ACK 超时、DONE 超时、重试次数 |
| `safety` | 最小 ToF 安全距离 |
| `sensors` | ToF 距离、限位信号、抓取确认 |
| `colors` | 追踪颜色列表 |
| `loop` | 循环休眠间隔 |

## 设备接口约定

视觉模块采用鸭子类型（duck-typing），真实硬件接入只需实现对应接口：

| 设备 | 接口方法 |
|------|----------|
| 相机 | `read() -> (bool, np.ndarray \| None)` |
| 扫码器 | `read() -> ScanResult \| None` |
| 传感器 | `tof_distance_mm`, `limit_triggered`, `grasp_confirmed` 属性 |

## 技术特点

- **模块解耦**：应用层、任务层、通信层、视觉层分层清晰，模块间通过接口约定耦合
- **仿真与实机对齐**：仿真模式使用真实状态机逻辑，确保仿真结果可信
- **安全优先**：所有动作执行前经安全门检查，未接入传感器明确告警不静默
- **容错恢复**：状态超时、通信断线、视觉异常均有恢复路径，避免永久卡死
- **可观测性**：全链路 JSONL 日志，支持离线复盘和参数调优
