# Qt 视觉调参界面 — 手工验收清单

## 启动

```bash
pip install PySide6
python -m tools.qt调参 --source 0
```

或 VS Code：**Qt Color Tuner**

## 颜色追踪页

1. 原图 / 掩膜 / 标注 三页签实时刷新
2. 调 HSV、min_area 后掩膜即时变化
3. 「保存当前页」只写颜色配置 JSON

## 站点标签页

1. 修改 dictionary / tag_size_mm / 映射表
2. 画面「标注/站点」页能看到 AprilTag 框与站名（有标签时）
3. 「保存当前页」写入 `站点标签.json`，默认映射可整表替换

## 精定位页

1. 修改采样数与阈值后点保存
2. 打开 `精定位配置.json` 确认数值一致

## 实机基础页

1. 修改相机源 / 分辨率 / 启用颜色 / ToF / sleep
2. 「用实机相机源重连预览」切换预览相机
3. 「全部保存」后 `实机配置.json` 更新

## 比赛流程

1. Qt 调好 → 全部保存 → 关闭 Qt
2. 一键启动实机任务（不再开 Qt）
