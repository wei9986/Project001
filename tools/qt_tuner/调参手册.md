# 视觉模块调参手册（赛前）

Qt 界面只用于**赛前/调试**。调好后点「全部保存」→ **关闭 Qt** → 再一键启动实机任务。比赛中不要同时开 Qt（会抢相机）。

---

## 1. 怎么启动

```bash
# 在 Project001-opencv.gcs 目录下
pip install PySide6
python -m tools.qt调参 --source 0
```

- `--source 0`：本机摄像头编号（0/1…）
- 也可用图片或视频路径做离线预览，例如 `--source D:/samples/red.jpg`
- VS Code：运行配置 **Qt Color Tuner**

界面右侧三个预览页签：

| 页签 | 用来看什么 |
|------|------------|
| 原图 | 真实画面、光照、目标位置 |
| 掩膜 | HSV 是否把目标“抠干净”（白色=命中） |
| 标注/站点 | 颜色框 + AprilTag 站点名 |

左侧四个调参页签依次对应四份 JSON。

---

## 2. 推荐调参顺序（赛场 10 分钟版）

按这个顺序做，少走弯路：

1. **实机基础** → 相机能出图、分辨率正确、启用要用的颜色  
2. **颜色追踪** → 每种物料色单独调通（掩膜干净、标注稳定）  
3. **站点标签** → 字典/物理尺寸/ID 映射正确，标签能认出  
4. **精定位** → 按抓取稳定性微调（无预览，靠经验与实测）  
5. **全部保存** → 关闭 Qt → 启动检查 → 一键实机

## 3. 颜色追踪（最重要）

配置文件：`config/颜色追踪配置.json`

### 3.1 操作步骤

1. 选颜色（red / green / blue / yellow）  
2. 红色有两段 HSV（`range 索引` 0 和 1），**两段都要调**  
3. 先看 **掩膜**：目标区域尽量白，背景尽量黑  
4. 再看 **标注**：框住目标、不乱飘、不串色  
5. 「保存当前页」或最后「全部保存」

### 3.2 HSV 怎么调

OpenCV HSV：`H=0~179`，`S/V=0~255`。

| 滑块 | 作用 | 怎么拧 |
|------|------|--------|
| H low / H high | 色相范围 | 先框住目标色；偏色就扩一点，串色就收一点 |
| S low | 饱和度下限 | **最常用**：杂色/灰背景误检 → 提高；目标发灰检不到 → 降低 |
| S high | 饱和度上限 | 一般保持 255 |
| V low | 亮度下限 | 暗场检不到 → 降低；反光/高亮噪声 → 提高 |
| V high | 亮度上限 | 一般保持 255；强反光误检可略降 |

**实操口诀：**

1. 掩膜几乎全黑 → 先降 `S low` / `V low`，再略扩 H  
2. 掩膜很多白噪点 → 先升 `S low`，再略收 H，最后加形态学  
3. 红色跨 0°，必须调 **range 0 和 range 1** 两段  

常见起点（仅参考，以现场为准）：

| 颜色 | H 大致区间 |
|------|------------|
| red | 0–10 与 160–179（两段） |
| yellow | 20–35 |
| green | 35–85 |
| blue | 90–130 |

### 3.3 形态学

| 参数 | 作用 | 建议 |
|------|------|------|
| kernel_size | 开闭运算核大小（奇数） | 3~7；噪点多加大 |
| open_iterations | 开运算：去小白点 | 1~2；过大吃掉小目标 |
| close_iterations | 闭运算：填目标内部黑洞 | 1~2 |

顺序：先把 HSV 调到“大致对”，再用开运算清噪，闭运算补洞。

### 3.4 Tracking（检出与稳定性）

| 参数 | 作用 | 怎么调 |
|------|------|--------|
| min_area | 最小面积（像素） | 远/小目标检不出 → 降低；灰尘误检 → 提高。常见 300~2000 |
| max_area | 最大面积，`0=不限制` | 只要屏蔽超大色块时才设 |
| confirm_frames | 连续确认帧数才算有效 | 抖→加大（3~5）；响应慢→减小（2~3） |
| max_match_distance | 帧间关联距离（px） | 目标移动快跟丢 → 加大；串 ID → 减小 |
| max_lost_frames | 丢失后保留轨迹帧数 | 短暂遮挡丢目标 → 加大 |
| min_circularity | 圆形度下限 0~1 | 圆物料可开 0.5~0.8 滤异形；不规则物保持 0 |
| min_solidity | 实心度下限 0~1 | 滤镂空/碎轮廓；一般先保持 0 |
| ROI | 只在矩形内检测 | 背景杂色多时启用，框住工作台区域 |

### 3.5 Preprocess

| 参数 | 作用 | 建议 |
|------|------|------|
| blur_ksize | 高斯模糊核（奇数） | 噪声大用 5/7；边缘糊别太大 |
| blur_sigma | 模糊强度，`0=自动` | 一般 0 即可 |

### 3.6 颜色页验收标准

- 掩膜：目标主体白、背景黑，偶有小噪点可用形态学消掉  
- 标注：稳定框住，不在相近颜色间乱跳  
- 换光照（开灯/遮光）再看一眼，必要时略放宽 V/S

## 4. 站点标签（AprilTag）

配置文件：`config/站点标签.json`  
预览请切到右侧 **「标注/站点」**。

| 参数 | 作用 | 怎么调 |
|------|------|--------|
| dictionary | 标签字典 | 必须与实物打印时一致，默认 `DICT_APRILTAG_36h11` |
| tag_size_mm | 标签黑边外边长（毫米） | 用尺子量实物；错了位姿尺度会偏（无标定仅影响部分 3D） |
| 映射表 tag_id → station_id | 逻辑站点名 | 与任务/状态机约定一致 |

常见映射（可按赛场改名，但要和任务代码一致）：

| tag_id | station_id |
|--------|------------|
| 1 | material_area |
| 2 | assembly_area |
| 3 | finished_area |

**注意：**

- 改 dictionary 会重建检测器；改映射表只更新名字，实时生效  
- 认不出：检查字典、打印清晰度、反光、距离、是否被裁切  
- 保存后写入 JSON；比赛运行读的是这份文件

## 5. 精定位（抓取前稳定采样）

配置文件：`config/精定位配置.json`  
界面**无实时曲线**，按抓取实测改数值。

| 参数 | 含义 | 偏松（更容易过） | 偏严（更稳但更慢/易超时） |
|------|------|------------------|---------------------------|
| required_samples | 需要连续稳定样本数 | 3~4 | 5~8 |
| max_spread_mm | 样本散布上限（mm） | 6~10 | 3~5 |
| max_step_mm | 相邻样本跳变上限（mm） | 40~60 | 20~30 |
| timeout_ms | 总等待超时 | 2000~3000 | 1000~1500 |
| lost_timeout_ms | 跟丢判定时间 | 400~600 | 200~300 |

**怎么调：**

- 经常 `TIMEOUT` / 来不及抓 → 放宽 spread/step，或加长 timeout，或减少 samples  
- 经常抓偏 / 坐标乱跳也判 STABLE → 收紧 spread/step，增加 samples  
- 目标短暂遮挡就 LOST → 加大 `lost_timeout_ms`  

需要相机标定（`实机配置.calibration`）才有可靠世界坐标；未标定精定位世界坐标能力受限。

## 6. 实机基础

配置文件：`config/实机配置.json`

| 参数 | 作用 | 建议 |
|------|------|------|
| camera.source | 比赛用相机 | 与现场 USB 口一致；可用「用实机相机源重连预览」验证 |
| width / height / fps | 分辨率与帧率 | 与标定、算力匹配；常见 1280×720@30 |
| 启用颜色 | 实机 ColorTracker 颜色列表 | 只勾比赛用到的色，少算一点更快 |
| safety.minimum_tof_mm | ToF 安全距离下限 | 按机械结构留余量，默认约 80 |
| loop.sleep_s | 主循环休眠 | 默认 0.002；CPU 过高可略增 |
| 实机显示 OpenCV 窗口 | 比赛是否弹窗 | 赛场建议关（`display=false`） |

串口（`controller.port` / `scanner.port`）请直接改 JSON 或后续扩展；当前 Qt 页主调相机与颜色开关。

## 7. 保存与比赛衔接

| 按钮 | 行为 |
|------|------|
| 保存当前页 | 只写当前左侧页签对应 JSON |
| 全部保存 | 四份配置一起写盘 |
| 全部重载 | 从磁盘重新读入（放弃未保存改动） |
| 重置追踪 | 清空颜色跟踪内部轨迹状态 |

赛前闭环：

```
Qt 调参 → 全部保存 → 关闭 Qt
→ python -m tools.启动检查（或项目既有预检）
→ 一键实机运行（读 JSON，不再开 Qt）
```

## 8. 现场故障速查

| 现象 | 先查 |
|------|------|
| 黑屏 / 无法打开相机 | 相机源编号；是否被其它程序占用；关 Qt 再开实机 |
| 掩膜全黑 | HSV：降 S/V low，扩 H；红要调两段 |
| 掩膜满屏白噪 | 升 S low；收 H；加 open；提高 min_area |
| 有掩膜但无框 | min_area 太大；圆形度/实心度过滤过严 |
| 框乱跳 / ID 乱串 | confirm_frames↑；max_match_distance↓；开 ROI |
| 站点认不出 | dictionary 是否匹配；标签尺寸/清晰度/距离 |
| 精定位总超时 | 放宽 spread/step/timeout；确认标定与目标世界坐标 |
| 比赛与预览不一致 | 是否忘记保存；实机 `colors` 是否勾选了对应颜色 |

---

## 9. 一页纸速记

1. **先出图，再抠色，再稳框，再站点，最后精定位**  
2. 颜色：看掩膜调 HSV → 形态学清噪 → min_area/confirm 稳框  
3. 红色：两个 range 都要调  
4. 站点：字典与实物一致，映射与任务名一致  
5. 精定位：不稳就放宽，抓偏就收紧  
6. **保存 → 关 Qt → 再开实机**
