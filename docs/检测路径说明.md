# 检测路径说明

## 当前主路径（已启用）

| 能力 | 模块 | 说明 |
|------|------|------|
| 物料颜色检测与跟踪 | `vision/颜色追踪.py` | HSV 多目标跟踪 |
| 工位识别 | `vision/站点定位.py` | AprilTag 36h11 |
| 抓取前精定位 | `vision/精定位.py` | 依赖平面标定 `world_mm` |
| 任务码 | `mission/扫码读取.py` | 串口扫码器 / 相机二维码 |

实机与仿真运行入口（`app/运行循环.py`、`app/实机运行.py`）**只消费上述路径**。

## 未启用（备用）

| 资源 | 状态 |
|------|------|
| `ultralytics` / YOLO | 依赖可安装，**主路径零引用** |
| `data/shapes_dataset/` | 形状数据集，备用未接入 |
| `models/` | 模型权重目录，当前为空 / 未用于生产 |

在赛题明确要求形状检测或 YOLO 之前，不要把 YOLO 接入运行循环，以免测试范围与部署体积失控。

## 配置提示

- `config/任务配置.json` 中的 `barcode_mapping` **当前未接入主流程**（保留供未来 Code128 定位）；主流程工位坐标使用同文件 `stations`。
- 比赛门禁：`python -m tools.启动检查 --profile competition`
