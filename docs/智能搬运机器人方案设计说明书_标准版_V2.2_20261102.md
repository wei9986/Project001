# <a id="__RefHeading___Toc4371_1224981351"></a>摘要

面向2027年中国大学生工程实践与创新能力大赛智能搬运赛项，设计一台自主完成任务二维码读取、两批六件物料抓取、粗加工区放置与回取、暂存、同色码垛和返回启停区的机器人。方案以固定工位作业为对象，将底盘到站、视觉定位、机构取放及结果复核组织成可追溯的任务闭环。

系统采用四轮麦克纳姆底盘、树莓派4B视觉上位机、STM32F407自研核心板与扩展板。取放机构由水平伸出R轴、垂直升降Z轴和V形舵机夹爪组成，车载设置三个独立V形料位。主作业相机随机构运动，负责物料与圆环定位并保留读码功能；固定相机承担主要任务码读取。视觉采用OpenCV下的HSV与Lab颜色特征、轮廓筛选和圆环拟合，不配置必需的神经网络训练与推理链路。

整机由单组3S磷酸铁锂电池供电，经分路稳压为计算、驱动、舵机与控制电路供电。通过编码器和惯性测量完成站间粗定位，到站后依据工位视觉细调。上下位机以带会话、序号及CRC16校验的协议交互，区分命令接收、执行完成和视觉复核，限制失联、重复执行及状态不一致风险。

本方案以整轮400s、最终放置中心径向误差不大于18mm作为首轮工程设计目标；按重新建立的负载假设，平均电池输入功率约55\.6W，400s单轮耗能约6\.18Wh。细项费用基准为5530元，计15%预备费后经费安排为6360元。实施按2026年11月2日至12月7日安排，并在校赛前一周冻结功能。本方案面向初赛回转体物料的校赛实现；决赛颜色与形状变化需另作适配验证。尺寸、性能与费用按正式规则、实物测量及样机试验冻结。

关键词：智能搬运；树莓派4B；STM32F407；两轴取放机构；传统视觉；同色码垛

# <a id="__RefHeading___Toc4375_1224981351"></a>1 任务分析与设计输入

## <a id="__RefHeading___Toc4377_1224981351"></a>1\.1 任务流程与编码

机器人从启停区出发，读取由四组三位数字构成的任务码，依次执行第一批转盘取料、粗加工放置与回取、暂存放置，再执行第二批转盘取料、粗加工放置与回取、同色码垛，最后返回启停区。每次转盘取料后先放入车载料位并确认占用，再开始下一件取料。

颜色编号采用1红、2黄、3蓝、4绿、5黑、6浅蓝。第1、3组指定两批颜色及取料顺序，第2组同时指定第一批粗加工与暂存位置，第4组指定第二批粗加工位置。工位位置1—3与评分精度环1—6使用独立字段。两批颜色集合、批内重复限制和暂存位置语义在任务解析时按正式文件校验。

任务示例452\+321\+254\+312中，第一批绿、黑、黄依次放入粗加工位置3、2、1；第二批黄、黑、绿依次放入位置3、1、2。依据参考资料第15页，第2组同时规定第一批粗加工与暂存位置，形成黄在1、黑在2、绿在3的下层映射；第二批暂存按同色下层实际中心落位，不照搬第4组粗加工位置。正式文件若对暂存另作规定，应同步更新任务映射与用例。

# <a id="__RefHeading___Toc4383_1224981351"></a>2 总体设计思路与系统架构

## <a id="__RefHeading___Toc4385_1224981351"></a>2\.1 方案选择与职责分配

采用“固定路线到站、局部视觉观察、底盘细调、机构取放、检测复核”的工作方式。麦轮提供横移能力；两直线轴完成伸出和高度变化；夹爪依靠V形导向与软接触提升定心和抓持适应性。三料位使六件物料分两批完整流转，任务身份贯穿抓取、暂存和码垛。

两轴机构相较多关节机械臂减少运动学与关节标定工作，但对料位沿同一取放平面的布局提出明确要求。本方案通过沿R轴方向布置三个料位满足这一约束，具体覆盖见第3章。采用传统视觉是基于固定工位、有限颜色及可控补光条件，效果由实物测试验证，不以算法简单替代精度要求。

# <a id="__RefHeading___Toc4391_1224981351"></a>3 机械结构与取放可达性

## <a id="__RefHeading___Toc4393_1224981351"></a>3\.1 底盘与总体布局

四个80mm麦克纳姆轮按X形安装，底盘方案尺寸采用280mm×280mm，轴距与轮距初取220mm，离地间隙初取15mm。上述为设计算例，不替代正式外廓与质量限制。电池布置于下层中部；核心板、树莓派与显示安装在上层并避开取放通道。IMU靠近车体中心并远离大电流线束。

定义底盘B坐标X向前、Y向左、Z向上。三个料位位于夹爪的同一竖直取放平面内，沿X方向依次布置；R轴伸缩方向与X平行。料架、相机与支撑板不得侵入夹爪的升降和持料通道。

在400mm净宽算例中，280mm车体居中单侧静态余量60mm。偏航2°时正方形投影宽约289\.6mm，单侧余量约55\.2mm，再扣停车误差和突出件。转弯与横移分别校核扫掠包络，装载物、支架及线束属于需要检查的外廓。

## <a id="__RefHeading___Toc4395_1224981351"></a>3\.2 R轴与三个料位的覆盖

R轴采用直线导轨与同步带，42步进电机驱动；MGN12与GT2为初选系列，最终按悬臂弯矩、皮带伸长和惯量选型。三个V形料位具有编号、独立占用检测、防滚边缘及夹指避让槽。相邻间距按物料投影和夹指包络确定，不能只按物料直径排布。

设全部取放点的前后极值为x\_max、x\_min，则几何覆盖跨度为x\_max−x\_min；另加原点退让与两端限位安全余量才得到机构行程需求。qR以回零后坐标为参考，不能把夹爪安装偏置或零点选取当作必须的取放跨度。底盘运动只改变机器人与场地的关系，不改变夹爪与车载料位的相对可达范围。

取料位中心x为−60、0、60mm，夹爪最小X为−80mm，外部目标X为200mm的布局算例，则料位对应R坐标20、80、140mm，外部目标对应280mm。最小取放跨度为200−\(−60\)=260mm；280mm是该零点约定下的最大工作坐标。若每端暂留10mm退让，可将约280mm作为机械有效行程的选型算例，具体原点与限位位置需在总装中重新定义。该例仅在物料与夹指包络允许60mm间距、场地工位允许该停靠姿态时适用。

约280mm为含示例退让的选型起点，尚非冻结尺寸；详细总装须校核最大伸出时的支撑长度、挠度、抗倾覆及完整收拢能力；实物间距或外部距离增大时继续重算。导轨、同步带及支撑结构的实际长度和车道内包络另行验证。

## <a id="__RefHeading___Toc4397_1224981351"></a>3\.3 Z轴与V形舵机夹爪

Z轴采用导轨与T8×2丝杆初选方案，有效行程160—200mm作为选型起点。其需求由转盘表面、料位高度、地面放置、第二层接触高度及跨越障碍的安全高度共同确定。跨料位转移时，夹持物底面必须高于已装物料和料架包络，并留制动及装配余量。正常行驶使用单独验证的低重心收拢姿态，不要求始终保持最高跨料位姿态。

夹爪采用V形固定掌与单活动指，金属齿舵机驱动，可换TPU指套提供摩擦和有限柔顺。开口、夹持高度及舵机工作区由物料实测冻结。对称两接触面的简化筛查可用总摩擦承载大于kmg；实际V形接触角、摩擦系数及活动指传力需按结构受力计算，不直接沿用平行两指夹爪公式。舵机转矩按活动指力臂和传动效率核算，并做最大质量持料试验。设丝杆导程p、升降载荷Fz、传动效率η，则Z轴静态驱动转矩筛查值为Fz×p/\(2πη\)，再计加速、摩擦及安全系数；R轴按移动质量、加速度、摩擦与带轮半径计算驱动转矩。转矩满足后还需校核丝杆临界转速、导轨悬臂载荷、支架挠度及最大伸展抗倾覆；物料质量和重心未测得前不作载荷合格结论。

丝杆型号不能独立证明自锁。Z轴设置经验证的保持措施，优先使用弹簧制动或其他失电保持结构；舵机失电后也不能假定保持夹紧。夹爪设计机械防脱或经验证的保持结构，急停和掉电试验中不得依赖软件持续供电避免落物。

## <a id="__RefHeading___Toc4399_1224981351"></a>3\.4 回零互锁与结构验收

各轴设置原点、软件限位、机械限位和动作超时；原点或端部限位仅证明端点状态，不能证明任意中间位置已到位。Z轴上下端设置限位，R轴设置原点与外端限位。回零采用低速寻找、退离、低速复寻，并验证开关常开、常闭或断线状态。未知姿态下先保持载荷并检查可观测状态，再按干涉验证后的顺序回零，不能直接同时回零两轴。

底盘正常行驶前要求机构进入已验证的收拢包络；底盘未停稳时禁止向工位伸展或下降。车内转移先抬至跨料位安全高度，再移动R轴，最后下降。占用矛盾、抓持不明、回零失效或限位异常时不继续执行绝对目标。

移动线束使用适合反复弯折的线材，按数据手册设置弯曲半径和应力释放，禁止裸排线承受拖链拉力。空载、满载、全行程、连续动作与重复装配后检查干涉、紧固、磨损、原点误差和相机外参。

# <a id="__RefHeading___Toc4401_1224981351"></a>4 电气系统与供电设计

## <a id="__RefHeading___Toc4403_1224981351"></a>4\.1 单组3S电池与分路拓扑

电源分为四轮驱动、R/Z执行、舵机、树莓派双相机及控制显示支路。示例12V电机与步进驱动支路需要升压或升降压，不能把9\.6V电池直接视为稳定12V。若最终驱动额定电压改变，重新核对电流、转矩、速度及能耗。

## <a id="__RefHeading___Toc4405_1224981351"></a>4\.2 树莓派与双相机供电

树莓派4B采用独立5\.1V低纹波支路\[7\]，校核线缆压降、连接器和USB负载。4A为预算裕量，不代表可从树莓派板载USB端口任意输出4A。两相机优先采用具有稳定驱动和唯一设备标识的USB方案，接入可区分的USB端口并检查真实共享总线拓扑；不能将两个物理端口视为两条独立总线；以640×480作为起始分辨率验证采集带宽与供电。

如相机总电流或接口预算超限，可增加由同一电池5V支路供电且禁止向主机反灌的有源USB集线器，纳入BOM和故障测试。相机选型冻结后复核双路实际电流、MJPEG或其他传输格式的CPU开销和掉帧，不以单相机测试代替双路验收。

## <a id="__RefHeading___Toc4407_1224981351"></a>4\.3 自研核心板与扩展板

核心板以STM32F407VGT6为基准\[8\]，包含最小系统、时钟、复位、SWD、看门狗相关电路、电源检测、串口及必要存储接口。CAN与外部存储按资源和调试需要预留。扩展板包含或连接四路直流驱动、两路步进、舵机、编码器、限位、料位占用、急停和显示，四路直流驱动元件或模块计入双板费用。

投板前逐项核对3\.3V供电反馈、稳压输入范围、启动时序、去耦、复位与启动脚、5V信号兼容及端口保护。外部Flash/FRAM如装配，其写保护等控制脚须有确定电平。USB、CAN和外接长线接口按环境配置ESD与瞬态保护。核心板逻辑地与动力回流规划分离后在指定位置连接，避免电机回流穿过测量地。

资源分配表覆盖芯片复用引脚、定时器通道、编码器模式、PWM、UART/DMA、步进脉冲、显示及中断优先级；只有无冲突且首板供电检查通过后，才接入动力负载。

## <a id="__RefHeading___Toc4409_1224981351"></a>4\.4 急停与电气安全

急停经硬件切断动力支路或可靠驱动使能，F407与树莓派保留故障记录供电。Z轴由失电保持结构防坠，夹爪由机械防脱或保持结构防落。接触器释放与制动建立时序须做载荷验证。急停复位不自动续跑。重新自检及人工启动只适用于台架或规则允许的新一轮；自主竞赛中需要人工触碰处理的故障按本轮结束处理，不借复位继续原轮任务。

电机与信号分槽布线，电机端抑制干扰，驱动近端配置去耦和储能。调试USB断开VBUS或采取合规隔离，避免外部供电并入机载系统。异常低压时先停止新增动作并安全保持，不在电压崩溃后依赖上位机发出撤离指令。

# <a id="__RefHeading___Toc4411_1224981351"></a>5 双相机传统视觉与标定

## <a id="__RefHeading___Toc4413_1224981351"></a>5\.1 相机分工与采集管理

固定读码相机Cq负责二维码板读取，安装在车架上，视场覆盖预定扫码距离。作业相机Cw安装于随R/Z机构移动的支架，负责物料、圆环及上下层识别，并保留二维码备用能力。只有固定读码通道超时且主作业相机处于已验证扫码姿态时才切换，不因单帧冲突反复切换。

两相机分别保存设备ID、内参、畸变、分辨率、曝光、增益和白平衡。现场标定后锁定成像参数；照明变化超出测试范围时进入重新标定或安全等待。补光向下并设置限光结构，不遮挡正式显示。运行时检查丢帧、设备断开和帧龄，设备重连后重新核验身份及配置。

读码阶段固定通道优先，作业阶段主相机优先；另一通道可降低采集频率。树莓派4B使用主动散热，采集、视觉和日志解耦，避免两个线程无限积压旧帧。性能目标为作业相机640×480下有效视觉输出不低于20fps，最终由双相机同时接入的10min压力试验验证。

## <a id="__RefHeading___Toc4415_1224981351"></a>5\.2 二维码与任务锁定

采用OpenCV QRCodeDetector识别\[2\]，检查四组三位数字、加号分隔、颜色1—6、位置1—3及位置组合规则。连续3次合法结果一致后生成只读任务对象，保存原始串并传给显示系统。固定与备用通道采用相同解析器，发生冲突时重新读码，不能投票拼接不同字符串。

显示完整任务是离开扫码点的必要条件。未获得合法任务不启动取料；锁定后不同识别结果不覆盖当前任务。保留超时、重试次数和失败图像，计入整轮时间。

## <a id="__RefHeading___Toc4417_1224981351"></a>5\.3 HSV与Lab颜色判定

图像去畸变后在工位ROI内处理，结合颜色候选、面积、圆度、边界完整性和背景遮罩提取物料。HSV提供色相、饱和度及亮度特征，Lab提供亮度和色度差异辅助判定。黑色不依赖色相单独判断，蓝与浅蓝在固定曝光下分别建立样本分布。

每类以现场实物采样确定阈值或特征距离范围；设类别最小间隔、候选质量及连续帧一致性门限。OpenCV按8位图像处理时明确BGR输入，HSV的H通常取0—179，红色跨两端应分段设阈值；Lab编码范围随8位或浮点输入而变化，记录转换类型及阈值单位，不能混用不同量纲。几何轮廓和颜色冲突时重新观察，不强制取最近类别。阈值不是已校准概率，不能把0\.9质量分直接解释为90%正确率。

采集六色在阴影、反光、转盘运动、遮挡及夹爪入镜条件下的样本，按采集批次和场景划分标定集与独立测试集，避免相邻帧跨集合。测试输出六色混淆矩阵、宏平均F1及困难颜色误判。该过程是传统视觉标定与验证，不设置神经网络训练交付物。

## <a id="__RefHeading___Toc4419_1224981351"></a>5\.4 圆环定位与移动相机坐标链

圆环采用边缘与轮廓提取，优先将对应平面校正到俯视度量平面后拟合圆或同心圆，并剔除遮挡外点\[3—5\]。透视图像中椭圆中心通常不等于实际圆心的投影，不能直接以椭圆中心替代物理圆心；采用其他圆锥曲线求解时须经标定基准点独立验证。工位数字1—3用于语义绑定，环中心用于几何定位。多个可见中心的几何排列可辅助偏航修正，但应由标定模型将图像关系转换为平面姿态，不能直接用像素斜率当作车体偏航。

## <a id="__RefHeading___Toc4421_1224981351"></a>5\.5 分层定位与放置复核

相机内参重投影误差以px报告，平面定位误差用未参与标定的独立基准点按mm测量。转盘表面、地面放置、车载料位与下层顶面分别建立高度模型，物料高度变化后更新Z目标及映射。

码垛前记录下层身份、中心和边界；先快后慢下降，通过接触检测与有限柔顺限制下压。步数只表示指令运动，不等同于真实接触或到位；电流阈值须台架标定且不直接解释为接触力。松爪后抬升至复核姿态，重新观察上下层及下层位移。遮挡无法直接看见下层时使用经验证的侧缘或多姿态复核，不直接宣告成功。

# <a id="__RefHeading___Toc4423_1224981351"></a>6 运动控制与固件设计

## <a id="__RefHeading___Toc4425_1224981351"></a>6\.1 底盘运动学与导航

采用X向前、Y向左、偏航逆时针为正，轮序为左前、右前、左后、右后。轮半径r，半轴距a、半轮距b，则四轮目标角速度依次为\[vx−vy−\(a\+b\)ω\]/r、\[vx\+vy\+\(a\+b\)ω\]/r、\[vx\+vy−\(a\+b\)ω\]/r、\[vx−vy\+\(a\+b\)ω\]/r\[6\]。装配后进行单轮正转、整车前进、横移与旋转测试，确认滚子方向和接线符号。

固定路线由直行、横移、转向及工位观察点组成，编码器与IMU提供粗定位。四轮独立速度闭环，航向外环校正偏航，到站后视觉修正。首轮站间限速0\.25m/s、局部接近0\.05m/s作为试验起始值，配合限加速度过渡，满载及低电量分别验证。

方向性ToF用于减速与停车，不承担全场建图。制动阈值按反应距离、实测制动距离和安全余量计算；失联反应期间移动量也计入。传感器对黑色、斜面和空隙的失效纳入测试，不作为唯一防碰撞依据。

## <a id="__RefHeading___Toc4427_1224981351"></a>6\.2 R/Z轨迹与动作控制

R/Z采用加减速受限的位置轨迹，步进脉冲由定时器或DMA等确定性机制产生。回零建立坐标有效标志，超时、堵转迹象或位置可信度丢失后废弃该标志。开环步进的脉冲累计不构成实际位移反馈，关键到位应以限位、参考检测或其他独立方法验证；需要编码器时纳入接口与费用变更。

底盘细调优先消除横向与偏航偏差，R轴补偿前后伸出，Z轴控制高度。夹爪通过开度、占用或夹持检测确认，不能仅靠舵机指令角和固定等待判断抓取成功。跨料位转移中的已装物料视为障碍，使用预先验证的安全高度和路径。

## <a id="__RefHeading___Toc4429_1224981351"></a>6\.3 实时任务与资源分配

采用FreeRTOS组织控制与通信。安全检查、看门狗及关键中断不依赖上位机响应；显示、日志低于控制任务优先级。控制任务目标与实际执行时间分别记录，测速窗口根据编码器分辨率和低速量化选择，不强制所有环节按1ms更新。

# <a id="__RefHeading___Toc4431_1224981351"></a>7 完整作业流程与异常处理

## <a id="__RefHeading___Toc4433_1224981351"></a>7\.1 上电自检与读码

上电检查电池、电压、急停、限位和料位状态，验证双相机设备ID、参数及串口会话。机构回零按已验证顺序执行，空料位与夹爪状态确认后进入待机。唯一启动按钮触发自主任务，启动后固定相机读取任务码、校验并静态显示，再进入原料区路线。

## <a id="__RefHeading___Toc4435_1224981351"></a>7\.2 转盘取料与车载存放

到站时机构进入观察姿态，识别目标颜色及运动状态。优先停位抓取，最近若干帧满足中心位移与标定速度阈值后锁定；初设最近5帧最大中心位移小于2px、估计速度低于5mm/s作为试验起点，必须在底盘与相机停稳后结合帧间隔、模糊和标定精度验证。图像帧龄和姿态变化超过限值即重新观察。

仅检测当前停转不能证明未来仍会停留。需用实测最短停留、从停靠开始已过去的时间、识别时延及安全余量，保守估计剩余窗口；有可保证的窗口且覆盖伸出、下降、闭爪、抬升及必要退让时才进入转盘。若停留无可用下界，该停位抓取策略不得作为整轮可用能力放行。目标离开窗口即中止危险下降并安全抬升。取料后先上升至跨料位安全高度，再移动R轴到指定料位并下降放置，确认占用与夹爪释放后才取下一件。

转盘周期6—10s不保证停留时长，也不能推导最大等待仅6s。双方向分别观察至少30转，记录停留分布与最短窗口。无足够安全窗口时退出当前抓取；本方案不把未经验证的动态追踪抓取作为必达功能。

## <a id="__RefHeading___Toc4437_1224981351"></a>7\.3 粗加工与暂存码垛

粗加工区按任务位置逐件放置，松爪、抬升、工位存在确认后更新占用。完成三件放置后按正式要求执行PROCESS\_ACTION，再按任务顺序回取并确认工位空缺。若规定独立加工动作或最低停留，在节拍表中另列，不能默认为零。

第一批暂存建立颜色、目标位置、实测中心与层高映射。第二批根据同色下层定位，底盘先细调，机构按分层高度下降，检测接触并松爪。复拍确认身份、中心及下层位移；偏斜只允许按有限恢复策略抬升再定位，禁止在物料上横拖或继续硬压。

## <a id="__RefHeading___Toc4439_1224981351"></a>7\.4 静止限制与有界恢复

底盘静止计时独立于机构和通信。夹爪动作、料位切换、相机扫描和ACK不自动重置该计时。连续三件取放可能超过15s，应依据正式解释规划具有实际作业目的的分段停靠与重新观察；不采用无意义抖动规避规则。

预警阈值按15s减去机构进入可移动包络、合法撤离的最坏耗时及检测裕量计算；12s只在这些耗时合计不超过3s时可用。若三件连续作业无法在规则内安排有效移动，该工位流程需要重新设计，不能仅加计时器宣告合规。只有机构处于可移动包络且撤离路线合法、状态可确认时才执行撤离；无法安全移动时停止任务。该约束同时适用于粗加工、取回与码垛工位，不能只检查转盘。

每个动作最多2次恢复，且所有恢复共享整轮53s余量。恢复先保持或抬升至已验证安全状态，再重新观察和规划；物料归属未知时不盲目重发。急停、低压、失联或严重限位矛盾直接进入安全停止，失联后不默认自动收回机构。

## <a id="__RefHeading___Toc4445_1224981351"></a>8\.2 ACK与执行确认

ACK表示命令已通过接收、校验和执行条件检查并被接受；DONE表示执行结束并附实际状态，FAIL包含错误码和是否可恢复。被拒绝、忙碌及非法状态返回明确的NACK或FAIL。单一执行器命令串行化，未完成动作时新运动命令拒绝或按明确策略排队，紧急停止可抢占；不得在未定义队列语义下覆盖当前目标。上位机收到DONE后结合料位或工位检测再推进。相同会话与序号的重发返回缓存状态，不重复驱动物理动作；序号回绕前建立新会话并处理未完成命令。会话ID在复位后不得简单固定为零；采用持久化启动计数或握手分配，双方确认后才接受运动命令。同键不同载荷作为协议错误，缓存保留范围覆盖全部重发与迟到窗口。复位后先停止并核对实际状态，不靠丢失的RAM缓存推定动作未执行。

ACK初设100ms超时、最多2次重发，各动作独立定义执行超时。图像年龄在采集、发送及下位机接收时递增，目标有效期与动作超时分别管理。通信时间与时钟不确定度计入帧龄，超过目标有效期不启动新动作；已进入安全退出阶段按本地策略完成停止或保持。心跳20Hz，250ms未收到有效心跳触发本地受控停止作为初始目标；实际停止还包括检测、驱动与机械制动时间，按全链路实测验收。停止期间保持载荷，失联本身不授权自动撤离。

平移最坏情况线性上界15mm；在250mm作用距离上，0\.5°偏航贡献约2\.18mm，合计约17\.18mm，作为18mm径向目标的初始分配。该值尚需同时验证移动相机、柔性夹指与两轴传动，不是已实现精度。

参考资料第21页按物料底面与环边缘的可见关系判环，并非简单的中心距离阈值。目标有效内半径减物料底面外接圆半径及安全余量，仅作为底面完整包含于目标圆内的保守几何筛查，不能等同官方判分公式。验收采用实物放置及同视角判环记录，不由18mm目标直接推算保证得分。参考精度环1—6对应15、10、7、5、3、1分，环外或倾倒按正式规则执行，不将位置编号当作精度环编号。

# <a id="__RefHeading___Toc4459_1224981351"></a>10 可行性论证与风险控制

## <a id="__RefHeading___Toc4461_1224981351"></a>10\.1 技术可行性

固定路线与工位视觉将全场运行分解为有限段运动和可复验动作；两轴机构降低关节数，沿R方向布置料位提供几何覆盖路径；树莓派4B承担传统视觉，F407承担实时控制，任务复杂度与实时约束分层处理。

按本节负载与可用容量假设，能量估算具有连续三轮的初步余量，精度预算给出约17\.18mm的初始上界，节拍分配形成400s目标。三者为详细设计和样机试验提供依据，可行性成立仍依赖全部料位与工位可达、3S低压峰值供电稳定、转盘有安全窗口及正式时限允许。现有同类案例可供参考，不能替代本机验证。

# <a id="__RefHeading___Toc4485_1224981351"></a>14 创新设计与综合结论

## <a id="__RefHeading___Toc4487_1224981351"></a>14\.1 设计特点与对照验证

两轴机构与同平面三料位协同减少自由度，移动相机分姿态定位和身份复核约束同色码垛。采用相同任务、物料和速度，对照固定坐标与视觉修正的误差及耗时，对照顺序记录与身份复核的错序检出及恢复效果；完整保留失败样本，故障注入另行统计。

可换指套与料位导向件作为制造改进候选，在规则允许的制造或调试环节装车并复测，3min现场调试期间不得更换零部件。参考初赛A/B/C权重20%/10%/70%，按正式评分表组织设计图、加工记录、测试和实物录像；创新评价由实际改进与对照结果支持。

## <a id="__RefHeading___Toc4489_1224981351"></a>14\.2 综合结论

本方案以树莓派4B传统视觉、F407自研双板、R/Z两轴夹爪和3S电源形成统一设计。加工前冻结取放点覆盖、载荷保持和峰值供电，随后依次完成台架、单站与整轮验证，以正式规则及原始试验记录形成最终验收结论。
