# 两周开发进度记录

本目录用于记录每天的开发内容、测试结果、问题和下一步计划。

## 每日规则

每天结束前必须完成：

1. 完成本日任务，或记录未完成原因。
2. 运行当天要求的测试命令。
3. 保存测试报告和日志路径。
4. 填写当天 Markdown 记录。
5. 检查 `git status`，确认没有误加入文件。
6. 提交 Git commit 并推送到 GitHub `main` 分支。

## 提交格式

```text
day01: setup vscode and baseline
day02: validate runtime loop
day03: tune color tracking
day04: validate fine localization
day05: validate camera calibration
day06: validate AprilTag stations
day07: validate scanner and task plan
day08: validate mission state machine
day09: validate serial protocol
day10: add safety and sensor faults
day11: add offline replay scenarios
day12: add logs and performance metrics
day13: prepare Raspberry Pi deployment
day14: freeze baseline and handoff
```

## 推送前检查

```powershell
git status --short
& '..\.venv\Scripts\python.exe' -m unittest discover -s tests -q
& '..\.venv\Scripts\python.exe' -m tools.启动检查 --json
```

确认没有误加入数据集、模型、缓存和运行日志后，再执行：

```powershell
git add <本日相关文件>
git commit -m "dayXX: <本日主题>"
git push origin main
```

## 重要说明

当前仓库除了初始 README 外，大部分项目文件尚未提交。`data/` 中约有 100 MB 图片，`models/` 中有模型文件。首次完整提交前必须确认这些大文件是否上传；模型和数据集更适合使用 Git LFS 或单独的数据存储。
