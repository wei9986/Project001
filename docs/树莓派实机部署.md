# 树莓派实机部署

## 部署前检查

1. 在树莓派创建 Python 3.10+ 虚拟环境，安装 `requirements.txt`。
2. 接入相机和 F407，使用 `ls /dev/ttyUSB* /dev/ttyACM*` 确认 F407 串口名。
3. 修改 `config/实机配置.json`：相机编号和 F407 串口必须与实物一致。默认 `scanner.mode` 为 `camera_qr`，不需要扫码器串口。
4. Pi 用户需要有串口权限：`sudo usermod -aG dialout $USER`，重新登录后生效。
5. 运行 `python -m tools.启动检查 --require-hardware --json`。通过后才可启动实机模式。

## 启动

```bash
chmod +x scripts/启动视觉实机.sh
./scripts/启动视觉实机.sh
```

默认无界面运行。需要调试画面时，将 `display` 改为 `true`；无显示器部署必须保持 `false`。每次启动会在 `test_logs/<时间>_live/` 创建独立会话，包含：

- `events.jsonl`：设备、协议、状态机与异常事件；
- `vision.jsonl`：逐帧颜色识别结果；
- `actions.jsonl`：任务动作与 F407 对接记录；
- `scans.csv`：二维码/Code128 原始统计；
- `summary.json`：帧率、掉帧、扫码成功率与最终状态；
- `annotated.mp4` 和 `error_samples/`：标注录像与无目标样本。

## 协议约定

Pi 发送 `PING`、`PICK`、`PLACE_RING`、`ASSEMBLE`、`HOME`、`RECOVER`、`STOP`。F407 必须按同一 `sequence` 回 `ACK`，动作完成后回 `DONE`；`FAIL/ERROR` 会触发有限次数恢复，恢复失败后发送安全停止。ACK 不是动作完成。

## 扫码源

`scanner.mode: "camera_qr"` 表示从主相机画面解码任务二维码。程序只在状态机等待任务码时调用识别器，成功后立即进入任务流程。若后续改用 GM865/USB 扫码器，改为 `"mode": "serial"` 并补充 `port`、`baudrate` 和 `scan_type`。
